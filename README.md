# Text2Sim

**Agentic Physics-Based Simulation Generation with Distilled Expertise**

[Project website](https://simulation-intelligence.github.io/Text2Sim/) · [Paper](https://arxiv.org/abs/2609.36593) · [Video](https://youtu.be/vHiEMebIKWc)

## Website

The project homepage is hosted with GitHub Pages from this repository. Its static HTML, CSS, JavaScript, images, and videos are in `docs/`. The website was migrated from `Xiaoyu-Xiong/Text2Sim.github.io`, preserving its Git history.

To update the website, edit the files in `docs/` and push to `main`. The `Deploy Text2Sim website` GitHub Actions workflow publishes only `docs/`, keeping repository files outside that directory out of the website. The workflow can also be run manually from the Actions tab. No build step or package installation is needed.

GitHub Pages uses **GitHub Actions** as its publishing source under **Settings → Pages**. Keep asset URLs relative so they work under the `/Text2Sim/` project path.
